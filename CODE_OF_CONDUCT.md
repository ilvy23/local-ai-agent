# Code of Conduct

We want this project to be a friendly place for people of every background and experience level.

- Be kind and patient. Assume good intent, and say what confused or annoyed you without attacking anyone.
- Critique code and ideas, not people. No harassment, insults, discrimination or personal attacks.
- Keep discussions on topic and respect other people's time and privacy (no sharing of other people's
  private information).
- Help newcomers. "This confused me" is a useful contribution.

Maintainers may edit or remove comments, issues and pull requests that break these rules, and may block
people who do so repeatedly. To report a problem, contact a maintainer privately through GitHub
(a private security advisory or a direct message).

This is a short, plain-language code in the spirit of the Contributor Covenant.
